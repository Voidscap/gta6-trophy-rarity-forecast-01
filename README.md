Forecasts every GTA VI (PS5) trophy's earn rate on Exophase one week after launch, as five quantiles per trophy. It models earners and players separately, blends a saturating adoption curve with a damped log-time trend, and widens its spread with horizon and refresh lag.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
